ISEAR is a dataset for emotion detection based on self-reported emotional events. 
- This is a single-label seven class dataset with the emotion categories sadness, guilt, joy, anger, shame, disgust, and fear. 
- Each instance contains two columns: the first column is the emotion label and the second column is the text. 
- The texts are written in relatively standard English. 
- The training, validation, and test sets contain 5,341, 1,150, and 1,146 instances respectively, and the class distribution is roughly balanced across the seven emotions.
